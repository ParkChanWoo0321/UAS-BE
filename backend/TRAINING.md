# 선박 감지 학습

프로젝트 백엔드를 실행하고 관제 콘솔 상단의 **선박 감지 학습**을 엽니다. 기본 주소는 `http://127.0.0.1:8765/#training`입니다.

## 첫 설치

프로젝트 루트에서 CPU 학습 환경을 준비합니다. 기존 FastAPI 실행 환경과 별도로 설치합니다.

```bash
python3 -m venv backend/.training-venv
backend/.training-venv/bin/python -m pip install --index-url https://download.pytorch.org/whl/cpu "torch==2.8.0" "torchvision==0.23.0"
backend/.training-venv/bin/python -m pip install -r backend/training-requirements.txt
```

기본 가중치는 기존 프로젝트의 `ChineseFishingVessel_ws/yolov8n.pt`입니다. 다른 위치에 둔 신뢰할 수 있는 기본 가중치를 사용하려면 백엔드를 실행할 때 `MARITIME_TRAINING_WEIGHTS`에 절대 경로를 지정합니다.

## 사진과 영상으로 학습하기

1. **사진·영상 선택**에서 여러 파일을 선택하거나 **폴더 선택**을 사용합니다. 화면에서 배치 진행률과 실패한 파일을 확인할 수 있습니다. 파일 내용이 같은 중복 업로드는 건너뜁니다.
2. 데이터셋에서 이미지를 열고 선박마다 박스를 그립니다. **라벨 저장하고 다음**을 누르거나, 배경 이미지는 **선박 없음으로 저장**을 누릅니다. 영상은 선박을 확인할 수 있도록 최대 32장으로 추출됩니다.
3. 선박 박스를 저장한 이미지가 2장 이상이면 **학습 시작**을 눌러 로컬 CPU에서 YOLO를 학습합니다. 검토된 이미지 전체를 학습과 검증에 나눠 사용합니다. 주석을 수정해도 시작한 학습에는 시작 시점의 라벨이 사용됩니다.
4. 완료 후 현재 모델의 **모델 다운로드**, **결과 CSV**, **학습 로그**를 확인합니다. 한 영상에만 선박 라벨이 있으면 같은 영상 안에서 시간순으로 나눠 검증합니다.

## 자료 삭제와 재학습

데이터셋에서 이미지를 열고 **사진 삭제** 또는 **영상 삭제**를 선택합니다. 영상은 해당 파일에서 추출한 모든 프레임과 라벨을 함께 지웁니다. 실행 중인 학습에 사용되는 자료는 해당 학습이 끝난 뒤 삭제할 수 있습니다.

삭제한 자료를 학습이나 검증에 사용한 결과는 **재학습 필요**로 표시합니다. 현재 학습 모델이 영향을 받으면 학습 화면의 현재 모델이 원본 가중치로 돌아갑니다. 영향을 받은 가중치의 이전 다운로드 링크도 사용할 수 없습니다. **남은 자료로 재학습**을 누르면 원본 모델에서 시작하며, 완료된 새 가중치가 현재 모델이 됩니다.

학습 자료, 라벨, 로그, 가중치는 `backend/.training-data/`에 저장합니다. 출력 가중치는 단일 클래스 `boat` 모델이며 클래스 번호는 `0`입니다. 이미 내려받은 파일은 다운로드 위치에 보관됩니다.
